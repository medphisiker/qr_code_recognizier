# Распознаватель QR code для TOTP

TOTP (Time-based One-Time Password) — это алгоритм создания временных одноразовых паролей, которые меняются каждые 30 секунд и используются для двухфакторной аутентификации (2FA).

Как работает TOTP

Связка с секретом: 

- При включении защиты сервис дает вам секретный ключ (обычно в виде QR-кода), который сохраняется на сервере и в вашем приложении-аутентификаторе.
- Привязка ко времени: Каждые 30 секунд приложение и сервер на основе этого ключа и текущего времени синхронно вычисляют одинаковый числовой код (обычно из 6 цифр).
- Проверка: При входе на сайт вы вводите пароль и текущий код из приложения. 
Сервер проверяет совпадение значений.

Главные преимущества
- Безопасность: Код действует всего полминуты, его невозможно использовать повторно или применить, если он перехвачен с опозданием.
- Работа без интернета: Приложению не нужна мобильная связь или Wi-Fi, так как для генерации кода используется только внутреннее время устройства и секретный ключ.
- Надежнее SMS: Код не могут перехватить через мобильного оператора или сбои связи.


## Шаг 1. Системная зависимость

Для работы библиотеки pyzbar для расшивроки QR code в Linux Ubuntu системе необходима общая библиотека распознавания кодов. Установите её через системный менеджер пакетов (если не ставили ранее):

```bash
sudo apt update && sudo apt install libzbar0
```

## Шаг 2. Создаем окружение

```bash
uv sync
```

## Шаг 3. Запуск через uv

Скрипт выведет полную ссылку и сразу отдельно напечатает очищенный секретный ключ, который вы сможете скопировать в KeePassXC без лишнего ручного удаления символов.
