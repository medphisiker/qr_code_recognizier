# Распознаватель QR code для TOTP

Распознает QR code для [TOTP](https://en.wikipedia.org/wiki/Time-based_one-time_password).

Приложение KeePassXC поддерживает генерацию одноразовых кодов по алгоритму TOTP.
Но добавление их в приложение обычно происходит через QR code.
Сам KeePassXC увы не умеет распознавать эти QR code.
Он может только добавлять их по секретному ключу.

Данный репозиторий содержит скрипт который:
- принимает на вход картинку QR code от Google аккаунта
- пишет в терминал секретный код который нужно будет добавить в приложение для TOTP (в нашем случае это KeePassXC)


## Шаг 1. Системная зависимость

Для работы библиотеки pyzbar для расшивроки QR code в Linux Ubuntu системе необходима общая библиотека распознавания кодов. Установите её через системный менеджер пакетов (если не ставили ранее):

```bash
sudo apt update && sudo apt install libzbar0
```

## Шаг 2. Создаем окружение

```bash
uv sync
```

## Шаг 3. Запуск через uv

Скрипт выведет полную ссылку и сразу отдельно напечатает очищенный секретный ключ, который вы сможете скопировать в KeePassXC без лишнего ручного удаления символов.
